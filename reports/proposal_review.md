## 2. 제안서의 데이터·알고리즘 약속

한국관광공사 국문 관광정보 서비스_GW가 필수 핵심이다. 무장애 여행 정보, 관광지 집중률 방문자 추이 예측 정보, 기초지자체 중심 관광지 정보, 관광지별 연관 관광지 정보가 추가 활용 대상으로 제시됐다. 외부 결합 데이터는 통일부 DMZ 관광/카페, 국가보훈부 현충시설, 병무청 나라사랑가게, TAGO 교통, 기상청, 국방부 공개 식단 또는 자녀가 공개한 식단·선호다.

`place_node` 정규화 후 접경성, 복귀 안전성, 가족동행 편의성, 민통선 실행 가능성, 호국·평화 맥락성, 연계 방문 적합성, 제도·혜택 활용성, 데이터 신뢰도를 점수화하겠다고 설명한다. 이 점수들의 실제 계산식·가중치·검증 자료는 제출본에 없다.

**검증 전 인용하면 안 되는 수치:** 제출본은 TourAPI 약 26만 건/15종, DMZ 관광 614건, DMZ 카페 1,785건, 관광지 집중률 향후 30일 상대값이라고 설명한다. 이는 API 호출 성공이나 최신 원본 확보의 증거가 아니다. 원본 버전, 수집일, 실제 행 수, 강원 5군 필터 결과, 좌표 품질을 별도로 확인해야 한다. 전국 원본 행 수를 강원 서비스 보유 장소 수처럼 표현하면 안 된다.

## 3. 제출본 일정

실제 날짜·마감·인력 배분·정량적 완료 기준은 없다. 다음 네 단계만 제시됐다.

1. 강원 5군 `place_node`, TourAPI 강원 필터, DMZ·현충시설·카페 정규화, 지도·패스포트 UI.
2. 초대코드, 부모 브리핑룸, 복귀시계, 미션, 비공개 공유 카드, 휴가 씨앗 스탬프.
3. 집중률·기상·교통 위험 보정, 무장애/가족동행 필터, 식단 부가 연결.
4. 강원관광재단·접경 5군·보훈부·병무청·지역 사업자 협업. 타 지역 확장은 장기 계획.

따라서 실제 개발 일정은 공식 Notion의 현재 마감·배포·기능심사 조건을 확인한 뒤 다시 정해야 한다.

## 5. 수상 관점의 강화 제안

### 하나의 완결된 가족 시연

장병이 공개 만남 거점·남은 시간·부모 동행을 고르면 관광/식사/회복 2~3개 장소의 미션이 나온다. 각 장소를 선택한 TourAPI 근거와 민통선 조건을 열어볼 수 있다. 시간이 줄거나 비 조건을 바꾸면 미션이 실제로 축소·대체되고 안전마진이 갱신된다. 부모가 초대코드로 허용된 범위를 보고 도보 부담과 식사 선호로 대안을 제안한다. 동행 기록 후 패스포트와 정보가 제거된 공유 카드를 만든다. 이 흐름이 주요 기능의 연결성과 데이터 활용을 한 번에 증명한다.

### 점수 하나보다 이유와 불확실성

현재시각/체류/구간 이동/거점 이동/대기/버퍼를 시간 내역으로 보여준다. 영업·예약·신분증·접근성 값이 없으면 '확인 필요'로 표시한다. 미확인 값을 '불필요', 무장애 필드 부재를 '접근 불가', 현충시설 등재를 '보상 대상 확정'으로 변환하지 않는다. 데이터 없는 위험은 0점으로 소거하지 않는다.

### 강원 특화의 기능적 증거

5군 각 장의 역사·평화·회복 서사는 유지하되, 실제 운영조건이 확인된 대표 미션부터 완성한다. 공통 검색 앱과 구별되는 접경지역 방문 조건·가족 이동 부담·공개 만남 거점을 지도와 카드에서 직접 확인할 수 있어야 한다. 검증된 시설·지역상권 연결 수를 기준으로 시연 범위를 늘린다.

### 부모의 자율성

부모에게 별도 시작 버튼과 온보딩, 도보 상한, 식사 선호, 방문 날짜, 실내 대체지 제안, 자녀에게 제안하는 동작을 제공한다. 자녀 개인정보를 읽는 화면만 있으면 제출본의 공동 사용자 약속을 충족하지 못한다.

## 6. 비용 대비 줄일 기능

- 초기 실시간 TAGO 환승/막차 최적화: 지도 기반 거리 추정만으로 대중교통 가능성을 확언할 수 없다. 확인 링크와 수동 대기시간·안전 버퍼를 우선하고 실제 데이터 연동은 확보 후 확대한다.
- 관광지 집중률의 강제 전체 매칭: 원천 ID의 TourAPI 대응과 지역 커버리지가 검증되기 전 필수 경로에 넣지 않는다. 샘플/부분 적용을 표시한다.
- 군 장병 혜택과 부대별 식단: 제공 범위·인증·최신성 확인 비용이 크다. 공개 선호 입력·검증된 후보 안내로 범위를 좁힌다.
- 자동 최적 경로와 수백 개 미션 생성: 검증한 장소 조합에 실시간 조건 필터를 적용하는 설명 가능한 엔진을 먼저 완성한다.
- 실제 군 신원 인증·GPS 방문 인증: 제품 목적상 불필요한 민감정보와 심사 의존성을 만든다. 시연 방문 기록은 자체 기록임을 명시하고 공적 인증과 구분한다.
- 무장애를 단일 점수로 요약: '주차 확인, 경사 정보 미확인, 걷기 약 N분 추정' 등 실제 확보 필드와 근거를 먼저 보여준다.

## 7. 1차 시연에서 반드시 보일 행동

1. 첫 접속 → 장병과 부모 역할을 각각 선택할 수 있다.
2. 강원 공개 거점·상황·남은 시간·동행 조건을 입력한다.
3. TourAPI 출처가 있는 장소들로 미션이 생성되고 안전마진 산식이 설명된다.
4. 시간 축소/비/부모 도보 제한 중 하나를 바꾸면 결과가 달라진다.
5. 예약·신분증 등 방문 조건의 확인/미확인 상태가 드러난다.
6. 초대코드로 부모가 공유범위 안에서 브리핑을 받고 미션을 제안한다.
7. 패스포트 기록과 동행 스탬프가 유지되고 공유 카드에는 민감정보가 없다.
8. 원천 API 실패 시 마지막 검증 스냅샷과 갱신 시점·대체 상태가 표시된다.

## 8. 개발 전 남은 확인

공고·Notion 실제 내용, 심사 일정과 제출물, 서비스 URL 유지 조건, API 키 발급/활용 의무, 팀에 이미 발급된 키, 소스별 최신 버전·좌표·운영조건을 확인해야 한다. 이 문서의 전략 제안은 공식 요구사항 확인 뒤 조정할 초안이다.
