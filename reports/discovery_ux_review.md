# 둘러보기와 여행 실행 UX 검토

2026-09-08 · 이슈 #13 · ① 웹·앱 개발 부문

## 사용자가 끝내야 하는 세 가지 일

1. 지역에서 함께 갈 코스를 찾고 나의 날짜·만남 장소·방문 순서로 바꾼다.
2. 가족·연인·친구 그룹에 여러 여행안을 공유하고 함께 편집한다.
3. 실제 출발할 때 복귀시각을 확인하고 현재 출타에서 진행, 완료 후 기록한다.

## 결정과 수정

| 발견한 혼동 | 변경 |
|---|---|
| 둘러보기가 날짜·시간과 개인 복귀 여유를 요구 | 지역 5개·취향 3개로 추천 15개 탐색. 날짜와 시간은 선택 후 일정표에서 입력 |
| 비슷한 카페를 여러 코스에서 반복 | 장소 조합·지역 이야기가 다른 2–3곳 추천. 식사는 편집에서 선택 |
| 그룹 편집인데 브라우저 저장이라고 안내 | ‘공유 범위 확인’ 후 최종 공유. 취소 후 편집값 유지 |
| 만남 장소가 비어 있으면 출타 시작에서 막힘 | 시작 확인에서 장소 편집 연결. 저장/취소 후 복귀시각 보존. 즐겨찾기 없이도 같은 지역 중심 지도 초기화 |
| 고성을 둘러보다 직접 만들면 철원 설정 사용 | 탐색 중인 지역으로 빈 코스 생성, 만남 장소 미지정 |
| 현재 출타에서 다음 장소로 가는 행동이 없음 | 다음 장소의 방문 정보와 카카오맵 길찾기 |
| 지난 미완료 계획이 홈을 차지 | 다가오는 일정 → 날짜 미정 → 지난 계획 순, 지난 계획 표시 |
| 모든 사진을 관광공사 출처로 표시 | 사진별 원문·저작자·촬영시기·라이선스 별도 표기 |

## 유지와 축소

- 하단 탭은 홈 / 둘러보기 / 현재 출타 / 그룹 / 내 여행 5개 유지.
- 역할·감정 조건의 기존 상세 설정은 기존 계획 호환을 위해 유지하되 둘러보기의 필수 단계에서 제외.
- 패스포트와 방문 준비는 내 여행의 보조 기능. ‘휴가회수 레이더’의 진입 이름은 ‘현충시설 방문 준비’로 변경. 보상 보장은 하지 않음.
- 사진 부족은 실제 장소가 검증된 외부 사진으로 보완. 매칭·이용조건이 불명확한 후보는 검토 목록에 남기고 적용하지 않음.
- 관광정보는 한국관광공사 API 우선, 한도 초과 시 출처가 구분된 기본 공공자료 유지. TourAPI 응답 DB 적재는 하지 않음.
