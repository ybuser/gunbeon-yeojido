### 서비스 설명 — 붙여넣기

군번여지도 강원은 장병과 가족·연인·친구가 강원 접경지역 여행을 함께 계획하는 모바일 웹 서비스입니다. 철원·화천·양구·인제·고성에 특화하고 춘천·속초를 관문도시로 활용합니다. 추천 코스를 자기 일정으로 가져오거나 관광지를 직접 검색해 방문 순서와 체류 시간을 편집하고, 동행 그룹에 공유합니다. 개인 복귀 기준은 그룹에 자동 공개하지 않으며, 출발 전 계획과 현재 출타를 구분합니다.

한국관광공사 국문 관광정보의 장소 식별자·좌표·콘텐츠 유형·설명·운영 정보를 공통 장소 모델로 변환하여 검색, 일정 구성과 이동시간 추정에 사용합니다. 무장애 여행 정보는 동행자의 주차·도보·편의시설 확인에 활용합니다. 교통 시간은 거리 기반 추정임을 표시하고, 실제 길찾기는 외부 지도에서 확인하도록 연결합니다. 서비스 화면에 출처와 조회 상태를 표시합니다.

### 증설 사유 — 붙여넣기

공개 서비스와 기능심사 준비 중 국문 관광정보 `areaBasedList2`에서 HTTP 429 및 제공자 오류코드 22(일일 한도 초과)가 발생했습니다. 같은 확인에서 `ldongCode2`는 성공했으므로 키 누락으로 일괄 판단하지 않고 오퍼레이션별 사용량을 확인하고 있습니다.

현재 새로운 권역 조회는 법정동 코드 2회와 유형별 목록 5회의 외부 요청을 만듭니다. 실제 필요한 유형만 지연 조회하고, 중복 요청 및 오류 후 재시도를 억제하는 개선을 준비하고 있습니다. 장소 상세·검색·저장 일정의 참조 복원에도 별도 요청이 필요하므로, 첨부 산출표와 실제 콘솔 사용량에 근거한 운영 트래픽 증설을 신청하고자 합니다.

현재 관광 응답을 운영 서버 DB에 적재하거나 정기 동기화하지 않습니다. 저장 방식은 공모전 참가자 안내에 따른 별도 신청 절차를 확인하고 있으며, 본 트래픽 신청을 데이터 저장 허가로 해석하지 않습니다.

### 첨부할 근거

1. [사용 가이드](usage_guide.md)와 실제 공개 화면: 탐색 → TourAPI 검색/상세 → 일정 편집 → 그룹 공유.
2. [실측 오류·저장 정책 기록](tourapi_operations_policy.md): 9/8 확인, 키 제거.
3. [호출량 모델](api_capacity_model.json): 오퍼레이션별 예상량과 입력 가정. 아래는 **하루 500세션이라는 예시**, 실측이나 최종 요청량 아님.
4. 콘솔에서 확인한 현재 승인량·최근 일별 호출 이력. 로그인 화면/키는 첨부하지 않는다.
5. 기능에 사용한 실제 TourAPI 성공 이력. 한도 복구 후 제한된 한 번의 실연동으로 보완한다.

| 서비스/오퍼레이션 | 예시 현재 요청/일 | 여유 1.5배 후 1천 단위 올림 초안 |
|---|---:|---:|
| 국문 `ldongCode2` | 4,000 | 6,000 |
| 국문 `areaBasedList2` | 5,000 | 8,000 |
| 국문 `searchKeyword2` | 1,000 | 2,000 |
| 국문 `detailCommon2` | 3,500 | 6,000 |
| 국문 `detailIntro2` | 1,500 | 3,000 |
| 무장애 `ldongCode2` | 500 | 1,000 |
| 무장애 `areaBasedList2` | 250 | 1,000 |
| 무장애 `detailWithTour2` | 2,500 | 4,000 |

서비스 합산 한도라면 오퍼레이션별 올림을 단순 합산한 값 대신 전체 수요와 여유를 다시 계산한다. 표에는 QA/재시도/보조 API/정기 동기화를 포함하지 않았다. 제출 시에는 현재 계정 단위에 맞춘 **확정 표 하나**를 사용한다.

## 2. 저장 방식·호출 집계 문의 — TourAPI 담당 부서

안녕하세요. 2026 관광데이터 활용 공모전 ① 웹·앱 개발 부문 참가팀 ‘우리아들이군인인데여행계획을준비했대’ 대표 심윤보입니다.

군번여지도 강원은 장병과 동행자의 강원 여행 계획을 돕는 모바일 웹입니다. 서비스는 https://gunbeon-yeojido-gangwon.ybuser.chatgpt.site/ 에서 임시 비밀번호 1234로 확인하실 수 있습니다. 활용 API는 국문 관광정보와 무장애 여행 정보이며 요청 식별값은 MobileApp=GunbeonGangwon입니다.

국문 areaBasedList2에서 HTTP 429 / 오류코드 22가 발생해 운영계정 증설을 준비하고 있습니다. 다음 사항을 안내 부탁드립니다.

1. 동일 일반 인증키를 사용하는 국문·무장애 서비스의 승인 트래픽은 서비스별 합산인지, 각 오퍼레이션별인지와 일일 한도의 초기화 시각.
2. 운영계정 전환 또는 증설 신청 시 활용사례와 실제 호출 이력 외에 필요한 자료, 희망량 산출 단위, 예상 처리 기간.
3. 참가자 FAQ에 안내된 DB 저장 별도 신청서 양식·제출 경로·신청 주체. 신청 후 저장 시작에 별도 승인/회신이 필요한지도 부탁드립니다.
4. 강원 접경 5군과 춘천·속초의 필요한 장소 식별자·명칭·주소·좌표·분류·설명·방문/편의 정보·사진 URL을 저장하는 경우 허용 항목과 갱신·보관·삭제 기준.
5. 이미지 파일 복제 없이 URL만 보관하는 경우, 사용자가 저장한 일정의 장소 참조/일부 필드, 브라우저 페이지 수명 동안 메모리 응답 재사용, 법정동 참조 코드 설정에는 각각 어떤 기준이 적용되는지.

현재 관광 응답은 운영 DB에 적재하지 않으며 브라우저 페이지가 열린 동안 메모리에서 재사용하고 있습니다. 출처·조회 상태를 표시하고 실패 시 반복 호출을 억제합니다. 서버 저장은 안내받은 절차와 범위에 맞추고자 합니다. 인증키는 이 문의에 포함하지 않았습니다.
