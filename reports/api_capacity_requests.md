군번여지도 강원은 장병과 가족·연인·친구가 강원 여행을 함께 계획하는 모바일 웹 서비스입니다. 철원·화천·양구·인제·고성에 특화하고 춘천·속초를 관문도시로 활용합니다. 추천 코스를 가져오거나 관광 장소를 검색하여 방문 순서와 체류 시간을 편집하고 동행 그룹에 공유합니다. 여행 계획과 현재 출타를 구분하며 개인 복귀 기준은 그룹에 자동 공개하지 않습니다.

한국관광공사 국문 관광정보의 관광·문화·행사·숙박·음식점, 장소 식별자·좌표·설명·운영 정보를 검색과 일정 구성, 이동시간 추정에 사용합니다. 무장애 여행 정보는 동행자의 주차·도보·편의시설 확인에 활용합니다. 거리 기반 이동 추정과 실제 길찾기를 구분하고, 화면에 데이터 출처와 조회 상태를 표시합니다.

### 증설 사유 — 붙여넣기

2026-09-08 국문 관광정보 areaBasedList2에서 HTTP 429 및 제공자 코드 22가 발생했습니다. 같은 점검의 ldongCode2는 성공했습니다. 정상적인 5유형 관광 정보, 검색·상세·무장애 기능을 유지하며 개발·외부 테스트·기능심사를 진행할 충분한 트래픽이 필요합니다.

새 권역 조회는 국문 코드 2회와 유형별 목록 5회를 사용합니다. 장소 상세·검색·저장 일정 참조 복원·무장애 확인에도 별도 요청이 발생합니다. 동일 동작의 중복 처리와 오류 후 반복 재시도는 개선하되, 기능이나 추천 데이터 범위를 줄이지 않는 수요 산출표를 첨부합니다. 현재 승인량과 실제 호출 이력을 바탕으로 운영계정 전환 및 필요 시 추가 증설을 요청합니다.

관광 응답을 운영 서버 DB에 적재·정기 동기화하는 절차는 별도로 문의합니다. 본 트래픽 신청을 저장 허가로 해석하지 않습니다.
