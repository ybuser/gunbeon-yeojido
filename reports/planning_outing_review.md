# 계획·현재 출타 분리와 개인 장소 UX 메모

작성일: 2026-09-08. 이번 사용자 요청에 대한 독립 설계 검토다. 코드·배포 화면의 실제 동작을 검증한 결과가 아니다.

이번 범위는 공개 장소 확인 체크를 없애고, 부대 정문을 포함해 사용자가 선택한 개인 장소를 해당 브라우저의 즐겨찾기로 보관하는 것이다. 만남 장소는 즐겨찾기 또는 지도 직접 설정으로 고른다. 관광지 추가는 즐겨찾기를 먼저 보여주고 가까운 장소·검색을 유지한다. 빈 코스 저장을 허용하며, 계획은 고정 출발 기준으로 계산하고 현재 출타에서만 시간 경과를 반영한다. 스탬프는 여행 완료 확인 뒤에 제공한다.

## 놓치기 쉬운 전환·취소·복원 5개

| 상황 | 예상되는 혼란 | 최소 동작 |
| --- | --- | --- |
| 1. 지도에서 만남 장소를 바꾸다 취소 | 지도를 이동하거나 핀을 찍는 순간 기존 만남 장소가 바뀌거나 즐겨찾기에 저장될 수 있다. | 지도 선택은 임시 상태로 둔다. `이 위치로 설정`에서만 현재 코스에 반영하고 뒤로가기·닫기는 기존 선택을 유지한다. 즐겨찾기 보관은 별도의 명시적 동작으로 제공한다. 이름은 기본값을 제공해 입력을 강제하지 않는다. 공개 장소 확인 체크는 다시 넣지 않는다. |
| 2. 즐겨찾기 이름·위치를 수정하거나 삭제 | 즐겨찾기를 옮겼더니 예전에 저장한 코스·진행 중 출타의 만남 장소까지 바뀔 수 있다. | 코스에 선택할 때 장소의 당시 값 또는 독립 참조를 보존한다. 즐겨찾기 수정·삭제는 기존 코스와 진행 중 출타에 전파하지 않는다. 삭제 후에도 저장 코스는 복원 가능해야 한다. 관광지 추가에서 즐겨찾기를 선택하면 다른 추가 경로와 같은 배열에 들어가며, 중복 장소는 기존 항목을 안내한다. |
| 3. 빈 코스 저장·재열기·편집 취소 | 저장은 되었지만 장소가 없어서 상세가 오류가 나거나 다시 열면 자동 추천 장소가 채워질 수 있다. | 이름·장소가 없어도 기본 제목과 여행 ID로 `계획 중` 초안을 저장한다. 만남 장소가 없어도 초안 저장은 허용하고 `만남 장소 설정`·`관광지 추가`를 제시한다. 빈 코스의 지도·사진은 빈 상태로 표시한다. 저장 전 편집을 취소하면 마지막 저장 상태를 유지하고, 초안을 현재 출타로 시작할 때만 필요한 장소·시각을 확인한다. |
| 4. 계획 ↔ 현재 출타 이동·새로고침 | 계획의 남은 시간이 매분 줄거나, 탭을 누르기만 해도 출타가 시작되거나, 새로고침 후 시작시각이 현재로 바뀔 수 있다. | 계획은 사용자가 정한 출발 기준을 유지한다. 탭 전환은 보기만 바꾸며 `현재 출타로 시작`에서 진행 상태를 만든다. 진행 중에는 실제 시작 상태와 코스를 별도로 유지하고 현재 시각으로 재계산한다. 계획을 수정해도 진행 중 코스는 자동 변경하지 않는다. 재열기에서 시작 상태를 초기화하지 않고, 복귀 기준처럼 저장하지 않는 값은 재입력 전까지 판단 대기로 표시한다. |
| 5. 여행 완료 확인·취소·스탬프 복원 | 완료를 눌렀다가 취소했는데 기록이 이동하거나, 새로고침·중복 클릭으로 스탬프가 늘거나, 준비 스탬프가 실제 방문 인증처럼 보일 수 있다. | `여행을 완료했나요?`에서 취소하면 진행 상태를 그대로 유지한다. 확인한 여행 ID에만 완료 상태를 한 번 기록하고 스탬프 선택을 연다. 완료 상태와 이미 고른 스탬프는 재열기에도 유지하고 중복 추가를 막는다. 미완료 계획의 방문 스탬프 버튼은 제공하지 않는다. 휴가 씨앗은 준비 기록이며 실제 방문 스탬프와 분리한다. 완료·스탬프는 사용자 확인 기록이고 GPS·보상 인증을 의미하지 않는다. |

## 이번에 닫을 최소 범위

- 장소 선택 UI는 `즐겨찾기 / 지도에서 설정`으로 단순화한다. 관광지 추가는 `즐겨찾기 / 가까운 장소 / 검색`을 제공하고 지도 직접 설정을 기존 추가 경로와 연결한다. 즐겨찾기가 없으면 등록 방법을 안내하고 빈 목록을 오류로 처리하지 않는다.
- 즐겨찾기는 해당 브라우저에 저장되는 개인 장소임을 짧게 알린다. 삭제·수정·다시 선택을 제공한다. 탭이나 검색 조건을 바꿔도 편집 중 코스는 유지한다.
- 저장된 계획, 편집 중 초안, 진행 중 출타를 구분한다. 진행 중 출타는 최소 버전에서 한 개만 두고, 다른 계획을 시작하려 할 때 기존 출타로 돌아가기 또는 명시적으로 종료하는 선택을 제공한다. 진행 중 출타를 조용히 덮어쓰지 않는다.
- 계획 화면의 고정 출발 기준과 현재 출타의 실제 시작 기준을 각각 가까이에 표시한다. 계획 화면으로 돌아와도 진행 중 출타 상태는 유지한다. 실시간으로 다시 계산하는 상태와 예보 갱신은 구분한다.
- 빈 코스·한 장소 초안을 저장하고 복원할 수 있게 한다. 현재 출타 시작에 필요한 값이 빠졌으면 해당 입력으로 안내하며, 빈 코스에 안전권 수치나 방문 스탬프를 만들지 않는다.

## 개인 장소의 경계

개인 선택 장소에 부대 정문이 포함될 수 있다는 이번 요청을 반영하되, 개인 장소를 공공 관광지나 TourAPI 검증 장소로 분류하지 않는다. 즐겨찾기에 저장할 수 있다는 사실과 가족·공개 공유 허용은 별개다. 이름·정확한 좌표는 해당 브라우저의 개인 저장 범위로 유지하고, 가족 투영·공유 카드·분석 로그·오류 보고에는 넣지 않는다. 특히 직접 입력한 장소명과 코스명을 기존 공유 함수가 그대로 내보내지 않는지 확인해야 한다.

지도 직접 설정에서는 기기 현재 위치 수집을 강제하지 않는다. 외부 길찾기·주변 검색 등으로 선택 좌표가 외부 서비스에 전달되는 동작은 사용자가 그 기능을 실행할 때만 수행하고, 개인 장소를 표시한 것만으로 자동 실행하지 않는다. 지도 SDK의 네트워크 통신까지 포함해 모든 위치 정보가 기기를 벗어나지 않는다고 약속하지 않는다.

공개 장소 확인 체크를 다른 확인 체크로 대체하지 않는다. 저장 위치·공유 범위를 짧게 설명하고 동작 자체를 분리해 사용자가 결과를 예측할 수 있게 하는 것이 이번 최소 UX다.
