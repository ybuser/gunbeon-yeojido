# 카카오맵 호출 한도 운영 준비

확인일: 2026-09-08 KST. **무료 적용 여부 확인 → 불필요한 지도 재생성 제거 → 사용량 계측 → 필요할 때 유료 전환** 순서로 진행한다. 이 문서는 준비안이며 결제 설정·문의 발송은 하지 않았다.

## 현재 확인한 상태

- 카카오맵 한도 소진은 확인되지 않았다. [공개 시나리오 검사](qa/discovery/public-flow.json)는 2026-09-08 05:12 UTC에 실제 SDK로 통과했다. 이전 `disabled OPEN_MAP_AND_LOCAL service`는 활성화 설정 문제였다. 검사 성공만으로 현재 잔여량을 알 수는 없다.
- 계정 콘솔에 직접 접근하지 않아 **현재 유료 설정 여부·무료 쿼터 배지·활성화 순서·일/월 사용량은 미확인**이다. 이번 작업에서 유료 설정을 변경하지 않았다.
- 기본 지도 SDK와 공식 카카오맵 길찾기 링크를 사용한다. Kakao 장소 검색 REST, `services` 라이브러리, 경로 조회 REST는 현재 사용하지 않는다.
- 9/9 수정: 공유 SDK 로더와 동일 화면 지도 인스턴스 유지를 구현했다. 제목·날짜·체류시간 편집은 지도 객체를 다시 만들지 않고, 장소·좌표·순서 변경은 핀을 갱신한다. 실제 검증은 최신 하루 여권 전달 기록을 따른다.

## 공식 한도와 2026년 변경 사항

| 항목 | 무료 제공량 | 추가 사용 단가, VAT 별도 |
|---|---:|---:|
| 전체 API 월간 합산 | 3,000,000건/월 | API별 |
| 지도 Web SDK | 300,000건/일 | 0.1원/건 |
| 주소·좌표 변환 4종 | 각각 100,000건/일 | 0.5원/건 |
| 키워드·카테고리 장소 검색 | 각각 100,000건/일 | 2원/건 |
| 대중교통·도보·자전거 경로 조회 | 각각 1,000건/일 | 10원/건 |

지도, 장소 검색, 경로 조회는 별도 소비 항목이다. 무료 자격이 없는 앱에 위 무료량이 제공된다고 가정하면 안 된다. [공식 쿼터·가격](https://developers.kakao.com/docs/ko/getting-started/quota)

2026-07-21 이후에는 **개발자 계정 기준 첫 번째로 카카오맵을 활성화한 앱**에 무료 쿼터가 제공된다. 앱 정보의 `카카오맵 무료 쿼터` 배지가 확인 기준이다. 두 번째 이후 활성화 앱은 비즈월렛 연결과 유료 API 설정이 필요하다. **7월 21일 이전부터 사용하던 앱은 기존 무료 쿼터가 유지되는 예외**가 있으므로 활성화 시점을 함께 확인한다. [공식 이용 안내](https://developers.kakao.com/docs/ko/kakaomap/common), [2026-06-16 공지·07-21 시행](https://devtalk.kakao.com/t/api-notice-on-new-kakao-map-api-features-and-free-quota-policy/150222)

**월 300만과 일 30만을 동시에 관리**해야 한다. 월 합산에는 다른 Kakao API 사용도 포함된다. 운영자는 유료 설정한 API는 무료 사용분도 월 합산에서 차감하지 않는다고 설명했다. 따라서 일 무료량 이내여도 월 한도 때문에 중단될 수 있고, 유료 전환 후에는 해당 앱 콘솔에서 월 합산 제외와 청구 내역을 확인해야 한다. [2026-03-31 운영자 답변](https://devtalk.kakao.com/t/topic/148977)

### 호출 집계 기준은 추가 확인 필요

공식 운영자 답변에 차이가 있다.

- 2026-07-09: 지도 객체를 생성하지 않아도 **인증 스크립트 요청 시 차감**된다는 설명. 테스트 앱에는 소량 쿼터가 제공된다는 안내도 있다. [답변](https://devtalk.kakao.com/t/topic/150600)
- 2026-08-03: **지도·로드뷰 객체 생성 시 차감**, 개별 타일 요청은 별도 차감하지 않는다는 설명. [답변](https://devtalk.kakao.com/t/web-sdk/150932)

SDK 요청과 지도 객체 생성을 각각 계측하고 콘솔 수치와 비교한다. “SDK를 한 번 받으면 지도 객체를 계속 생성해도 무료”로 단정하지 않는다. 아래 문의 초안으로 이 차이를 확인할 수 있다.

## 적용할 개선안

| 우선순위 | 변경 제안 | 완료 기준 |
|---|---|---|
| P0 | [MissionMap](../web/components/mission-map.tsx)의 지도 인스턴스를 유지하고, 실제 장소·좌표·순서 변경 때만 핀을 갱신 | 제목·날짜 편집 시 지도 재생성 0회, 사용자의 확대 위치 유지 |
| P0 | 두 지도 컴포넌트의 SDK 로더를 하나로 통합 | 한 문서에서 중복 요청·중복 로드 콜백 방지, 실패 시 무한 재시도 없음 |
| P0 | `sdk_requested`, `map_created`, `map_failed` 계측 | 개인정보·좌표·키 없이 이벤트 수를 기록하고 콘솔과 대조 |
| P1 | 모바일 일정표에서 필요할 때 지도 열기 | 홈·둘러보기·가이드에서는 SDK 요청 0회, 지도 선택 시에만 로드 |
| P1 | 지도 연결 실패를 일정표와 분리 | 저장된 개인 일정·장소 순서 유지, 외부 길찾기 사용 가능 |
| P1 | 자동 검사는 모의 응답, 릴리스 확인은 최소 실제 호출 | 테스트 반복 때문에 운영 쿼터가 소진되지 않음 |

현재 길찾기 URL은 유지한다. 앱키로 경로 API를 요청하는 기능이 아니라 사용자를 카카오맵으로 연결하므로 우리 앱의 경로 조회 호출을 추가하지 않는다. 외부 카카오맵의 가용성까지 보장하는 의미는 아니다. [공식 지도 URL 가이드](https://apis.map.kakao.com/web/guide/#routeurl)

카카오 타일·SDK를 임의로 서버에 복제하거나, 같은 서비스의 앱·키를 늘려 한도를 회피하는 방안은 사용하지 않는다. 무료 배지가 연습 앱에 있다면 공식 창구에 이관 가능 여부를 문의할 수 있지만 승인 결과는 보장하지 않는다. [이관 문의 사례](https://devtalk.kakao.com/t/topic/151479), [동일 서비스 다중 앱에 관한 운영자 안내](https://devtalk.kakao.com/t/topic/149220)

## 비용과 전환 기준

`M(d)`를 콘솔이 집계한 일별 지도 사용 건수로 두면, 계획용 비용 산식은 다음과 같다. 지도 외 API는 별도 합산한다.

- 무료 적용 앱 + 유료 설정: `Σ max(0, M(d) - 300000) × 0.1 × 1.1`원.
- 무료 미적용 앱 + 유료 설정: `Σ M(d) × 0.1 × 1.1`원.
- 유료 설정이 없으면 무료 한도 초과 시 차단된다. 자동 유료 전환을 가정하지 않는다.

| 가정: 매일 같은 사용량, 30일 | 사용량 | 예상 결과 |
|---|---:|---|
| 1,000세션/일, 세션당 집계 2건 | 월60,000건 | 무료 적용 앱은 지도0원 범위. 무료 미적용 앱은 월6,600원 |
| 50,000세션/일, 세션당 집계 3건 | 일150,000건·월450만건 | 무료 적용 앱도 유료 미설정이면 월 한도 먼저 초과. 유료 설정·월 합산 제외 적용 시 지도0원 예상 |
| 200,000세션/일, 세션당 집계 2건 | 일400,000건·월1,200만건 | 무료 적용+유료 설정이면 초과분 월330,000원 예상 |

위 값은 목표 트래픽이나 확정 견적이 아니다. 실제 집계 단위와 계정 자격을 확인한 뒤 계산한다. **초기 지출 목표는 0원**, 무료 소진이 예측될 때 비용을 검토한다. 유료로 전환한다면 월1만원 경보를 내부 운영 예산안으로 제안한다.

공식 유료 API 문서의 금액 한도 상세는 현재 카카오톡 공유를 설명한다. **카카오맵에 월1만원 강제 한도를 설정할 수 있다고 확인한 것은 아니다.** 내부 비용 경보와 지도 비활성화 스위치는 공급자의 청구 하드캡을 대신하지 못한다. [공식 유료 API 설정](https://developers.kakao.com/docs/ko/app-setting/paid-api)

## 계정에서 확인할 항목

키·카드번호 없이 다음 정보만 있으면 전환 판단이 가능하다.

1. 숫자 App ID, 일반/테스트 앱 구분, 카카오맵 사용 ON, 무료 쿼터 배지, 활성화 시점.
2. [쿼터]의 오늘 지도 사용량·제공량과 이번 달 전체 무료 사용량.
3. [통계 > 기간별 사용량]의 최근7일 지도·로컬 호출 건수.
4. [유료 API]의 카카오맵 사용 여부와 비즈월렛 연결 여부.
5. [플랫폼 키 > JavaScript 키 > JavaScript SDK 도메인]에 운영·개발 origin 등록 여부. 제품 링크 도메인 설정과 다르다. [공식 운영자 설명](https://devtalk.kakao.com/t/js-sdk-401-domain-mismatched-https-4fugfgg-anonymous-8081-exp-direct-caller-30/151184)

필요할 때의 유료 전환 절차는 **비즈월렛 생성 → 자동 결제카드 등록 → 앱 연결 → 카카오맵 유료 설정 → 사용내역 확인**이다. 개인 월렛도 가능하다. 과거 카카오맵 별도 심사나 사업자 등록을 현재의 일률적 필수 조건으로 안내하지 않는다. 결제 설정은 예산 결정 후 계정 소유자가 수행한다. [유료 API 설정](https://developers.kakao.com/docs/ko/app-setting/paid-api), [개인 월렛 안내](https://devtalk.kakao.com/t/api/146673)

앱 멤버의 이메일·모바일 푸시 알림을 켜고 수신 여부를 확인한다. 쿼터 임박·에러·청구 관련 알림을 활용하되, 내부 50/80/95% 경보를 카카오의 공식 고정 알림 단계로 표현하지 않는다. [공식 알림 설정](https://developers.kakao.com/docs/ko/getting-started/kakao-developers)
