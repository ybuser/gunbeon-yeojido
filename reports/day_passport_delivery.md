# 하루 여권 구현·검증 기록

2026-09-09 · **① 웹·앱 개발 부문** · 현재 배포 준비 중. GitHub/Sites 최종 연결 정보는 [인수인계](../docs/handoff.md)에 갱신한다.

## 적용한 경험

- **함께 쓸 하루:** 홈의 가장 가까운 개인 여행에 사진 창문 표지와 ‘계속 계획하기’. 소속 그룹·나머지 일정은 기존 목록에서 찾는다.
- **여유 조정:** 출발 전 일정표에서 한 곳 생략 또는 머무름 단축을 비교한다. 전체 연결 이동·복귀 이동·대기·날씨·동행 여유를 재계산한다. 적용은 편집기 반영이며 최종 저장이 필요하다. 후속 장소·시간 편집 전까지 되돌리기 가능. 예약/만남 장소 자동 생략 없음, 진행 중 출타 편집 잠금 유지.
- **하루의 한 장:** 여행 완료 확인 → 실제 다녀온 관광지 선택 → 스탬프 → 카드. 계획한 장소 전체를 방문 처리하지 않는다. 직접 입력 장소·개인 제목·정확한 시각/좌표를 공개 내보내기에서 제외한다. 이전 기록과 ‘장소 없이 기록’은 구분한다.
- **선택형 16초·4장면 안내:** 그룹 → 계획 → 여유 조정 → 기록. 무음, 재생/정지·이전/다음·바로 시작, 모션 감소 시 정지. 초대/재방문 강제 안내 없음. AI 영상은 이번 범위에 추가하지 않았다.
- **지도 유지:** SDK 로더 공유. 같은 화면의 제목/시간/도보 편집에서 지도를 재생성하지 않는다. 장소·좌표·순서만 핀 갱신. 다른 지도 화면의 정상 지도 생성은 유지한다.

## API와 저장

정상 TourAPI 5유형·검색·상세·무장애 기능을 유지한다. 운영계정 기본 일 10만과 운영팀 추가 증설 경로를 준비했으며 **실제 증설 신청/승인은 아직 없다.** [준비 문안](api_capacity_requests.md).

**9/9 11:28 KST 실제 키의 고성 조회: 5유형 전부 성공, 149개**(관광78·문화8·행사2·숙박17·음식44). [실연동 기록](qa/day-passport/tourapi-live.json). 9/8 한도 오류와 구분한다. 현재 승인량/전체 잔여량은 별도 확인 대상이다.

JSON/XML 22(일일)와 23(순간), 일반429, 인증 오류를 분리한다. 제공자의 Retry-After를 우선하며 미제공 시 일일10분/순간30초 뒤 사용자가 재요청할 수 있다. 자동 재시도 루프나 임의 일일 사용 예산은 추가하지 않았다. 관광 콘텐츠 DB 저장과 정기 동기화는 별도 공식 절차 후 적용한다.

화면 크기는 데스크톱 브라우저의 viewport/touch 모사다. 실제 Android/iPhone·Safari·현장 사용자 검증으로 확대하지 않는다. 반복 지도 시험은 별도 SDK 모형으로 생성 횟수/핀 갱신을 계측했다. 이 수치는 실제 Kakao 과금량 측정이 아니다.

## 검토 중 수정한 결함

1. 잘못된 복귀 시각이 1분 일정으로 보정되던 문제: 유효하지 않은 시간은 비교를 막는다.
2. 복귀 입력을 비운 뒤 출발 날짜를 바꿀 때 예외: 빈 시각 검사를 추가했다.
3. 완료/공유 대상의 TourAPI 저장 참조 미조회: 대상 참조를 우선 조회한다. 저장한 방문 ID의 정보가 없을 때는 ‘방문 없음’으로 표시하지 않고 내보내기를 막는다.
4. 완료 체크박스 이름 중복: 실제 화면 읽기 이름을 하나로 정리했다.
5. 카드 저장 버튼을 가리는 알림: 공유창에서는 알림을 숨겼다.
6. 사진 로딩 중 깨진 이미지처럼 보이는 상태: 이미지 준비 전 장소명 대체 표지를 유지한다.
