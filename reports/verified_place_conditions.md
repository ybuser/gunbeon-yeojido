# 철원 P0 미션: 공개 관광시설 방문조건 확인

확인일: 2026-09-07. 공식 웹페이지의 운영 안내와 변경 공지만 사용했다. 당일 현장 통제·좌석·주차 빈자리를 실시간 확인한 결과가 아니다. 미확인 예약·신분확인 값을 `false`로 바꾸지 않았다. 필드별 출처·확인일·증거는 `data/processed/verified_overrides.json`에 있다.

## 가장 중요한 수정

**철원역사문화공원은 2026-09-02부터 유료다.** 상설 관광소개 페이지에는 여전히 무료라고 쓰여 있으나, 2026-08-12 철원군 공지의 시행일과 첨부 PDF 요금표가 이를 갱신한다. 성인 개인 3,000원, 상품권 2,000원이며 어린이·청소년 개인 2,000원, 상품권 1,000원이다. 철원군민 무료 및 감면·면제에는 신분증/증빙이 필요하다. [최신 공식 공지](https://www.cwg.go.kr/www/selectBbsNttView.do?key=206&bbsNo=24&nttNo=288612)

PDF 1페이지를 직접 렌더해 표의 열 구분·시행일을 확인했다. 원본은 `data/raw/public/cwg-history-park-fee-20260812.pdf`이며 해시는 overrides의 `evidence_files`에 기록했다.

## 3. 철원역사문화공원 / 선택 시설 소이산 모노레일

신규 공식 장소 ID: `cwg:history-culture-park-1714`. 주소는 강원특별자치도 철원군 철원읍 금강산로 262다. **원본 CSV의 철원역사(舍)는 외촌리의 별도 유적이므로 병합하지 않는다.** 공원 입구의 공식 좌표는 아직 확보하지 않아 `lat/lon=null`이다.

| 항목 | 확인 결과 |
|---|---|
| 공원 운영 | 3~11월 09:00~18:00, 12~2월 09:00~17:00 |
| 공원 휴무 | 화요일·설날/추석 안내. 명절 당일 범위는 운영처 확인 |
| 공원 개인 입장료 | 2026-09-02부터 성인 3,000원, 어린이·청소년 2,000원 |
| 공원 상품권 | 성인 2,000원, 어린이·청소년 1,000원 |
| 주차 | 가능. 요금·빈자리 미확인 |
| 공원 예약/일반 신분확인 | 의무 여부 명시 없음 → 미확인 유지 |
| 문의 | 공원 070-7374-6401, 모노레일 070-7372-0362 |

시간·연락처는 [철원군 운영안내](https://www.cwg.go.kr/tour/contents.do?key=1714), 공원 휴무·주차 가능은 [한국관광공사 VISITKOREA](https://english.visitkorea.or.kr/svc/whereToGo/locIntrdn/rgnContentsView.do?vcontsId=216236)로 교차 확인했다. 공원 요금은 위 최신 공지 PDF를 우선한다.

모노레일은 공원 입장과 별도로 다룬다. 일반 개인 성인 7,000원, 청소년·어린이 4,000원이며 네이버 예매가 안내되어 있다. 사전예약이 반드시 필요하다는 명시는 없다. 하절기 탑승은 17시, 동절기는 16시에 종료한다. 기상특보 시 중지될 수 있고 임산부·반려동물 탑승 제한이 있다. 유아 문구의 이하/미만 기준은 원문이 불명확해 운영처 확인으로 남겼다. [운영기관 모노레일 안내](https://www.cwg.go.kr/tour/contents.do?key=1714)

UI 제안: 공원 산책과 모노레일 탑승을 분리해 선택하게 한다. 모노레일 대기시간을 0분으로 가정하지 않고, 미확보 좌표는 지오코딩 또는 TourAPI 응답의 동일 주소를 확인하기 전 지도 핀으로 만들지 않는다.

## 적용 원칙

- `confirmed` 값을 해당 필드에만 적용하고, 장소 전체를 검증 완료로 승격하지 않는다.
- 예약·신분확인은 일반관람과 감면/면제 증빙을 분리한다.
- 웹 수동 검증은 한국관광공사 OpenAPI 실시간 활용 실적을 대신하지 않는다.
- 방문 당일 예외 통제, 주차 잔여면, 실제 도보시간은 미확인이다.
- 군 내부 시설·작전지역은 이 검증 후보에 추가하지 않았다.
