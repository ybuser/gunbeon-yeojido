# 군번여지도 강원 1차 기능심사 시연 대본 초안

작성일: 2026-09-07. 대상은 **① 웹·앱 개발 부문**이다.

**약 3분은 팀 내부의 설명·연습 권장 길이이며 공식 영상 요구사항이 아니다.** 확인한 공식 안내에는 시연영상 의무나 길이가 명시되어 있지 않다. 이 문서는 현재 소스코드에서 확인한 화면·이벤트를 기준으로 썼다. 이 대본대로 수행한 브라우저 검증, 최종 제출 스크린샷, 최종 PDF, 녹화 영상은 아직 준비되지 않았다.

## 녹화 또는 공식 시연 전 준비

1. 배포 URL을 스마트폰과 데스크톱에서 열어 5개 흐름을 직접 확인한다. 브라우저 UI·레이아웃과 계산 숫자는 대본 작성만으로 검증되지 않는다.
2. 승인된 공공데이터 키를 서버 비밀값으로 설정하고 국문 법정동 코드·목록·상세, 무장애 목록·상세를 실제 호출한다. API 키·키가 든 요청 URL·운영자 콘솔은 녹화하지 않는다.
3. `데이터·출처`에서 현재 권역의 수신상태와 수신시각을 확인한다. 미연결 화면이라면 장애 대체 시연은 가능하지만 **공사 OpenAPI 필수 활용을 검증한 제출 시연으로 완료 처리하지 않는다**.
4. 철원군을 기본 권역으로 정하고 당일 조회 결과에서 관광·문화시설, 휴식 장소, 상세정보를 보여줄 대상을 고른다. 미션 구성과 마진은 현재 응답·시각에 따라 바뀌므로 아래에 고정 수치나 고정 장소 순서를 적지 않았다.
5. 공식 운영정보의 날짜·예약·신분확인 항목을 재확인한다. 무장애 상세는 `고석정 꽃밭`, `철원역사문화공원`의 과거 조회 근거가 있지만 실제 화면에 조회되는지 다시 확인한다. `고석정국민관광지`와 `고석정 꽃밭`을 같은 시설로 바꾸어 말하지 않는다.
6. 데모용 빈 브라우저 프로필을 사용한다. 실제 기록을 지우지 말고 시연용 계획·스탬프만 준비한다. 스탬프를 누를 때 여행을 실제로 했다고 주장하지 않는다.
7. Kakao 지도가 미연결이면 현재 개략도라고 명시한다. 외부 길찾기 링크는 새 탭으로 연결되는 개별 장소 링크이며 실제 복귀 경로 검증은 아니다.

## 추가 기능심사 확인 항목

3분 대본에 모두 넣지 않아도, 제출 전 실제 화면에서 확인할 항목이다.

- **권한 회수:** `공유 해제` 후 기존 코드로 연결이 차단되는지 확인한다. 코드 재생성 후 이전 코드가 무효인지도 확인한다.
- **동행 권한:** 연결하지 않았거나 `동행 스탬프 가능`을 해제한 상태에서 동행 스탬프 추가가 거절되는지 확인한다.
- **부모 제안:** `미션 제안 가능` 권한이 있을 때만 제안 버튼을 사용할 수 있는지 확인한다. 다른 권역의 제안은 권역 변경 안내가 나올 수 있다.
- **계산 경계:** 2시간·대중교통·도보 상한 초과·강풍을 각각 적용해 마진과 경고를 확인한다. 검증한 숫자를 그때 기록한다.
- **API 오류:** 별도 로컬 시험환경에서만 키 미설정·실패 응답을 재현한다. 실패를 인위적으로 정상 데이터로 바꾸지 않는다. 정상 배포의 키를 시연 중 제거하지 않는다.
- **부분 상세 실패:** 관광 상세가 성공하고 무장애 상세가 빈 응답이거나 실패할 때 두 상태가 구분되는지 확인한다.
- **저장:** 시연용 계획·스탬프의 새로고침 후 유지와 코드의 만료를 확인한다. 부모 브리핑 입력·현재 로그인 역할까지 영구 저장된다고 설명하지 않는다.
- **휴가회수 레이더:** 보조 시연으로 체크리스트와 현충시설 목록을 보여줄 수 있다. 등재가 보상 대상 인증이라는 뜻은 아니며 휴가 씨앗 스탬프도 준비 기록이다.
