# 군번여지도 강원 1차 기능설명서 내용 초안

작성일: 2026-09-07. **① 웹·앱 개발 부문**의 지정 양식에 옮길 내용 초안이다. 공식 양식을 대체하는 제출본이 아니며, 브라우저 시연 검증·화면 캡처·최종 PDF는 아직 없다. 아래 내용은 현재 구현 코드를 기준으로 작성했다. 실제 제출 전 변경 사항과 확인 결과를 반영하고 안내·편집 메모는 제거한다.

공식 양식은 PDF 1개·10MB 이하로 제출한다. 핵심 기능은 최대 5개이며 흐름도 슬라이드 복사가 가능하다. 아래는 기본 양식의 항목을 유지하고 기능별 흐름도를 5쪽으로 구성하는 **13쪽 편집안**이다. 13쪽은 팀의 편집안이지 공식 총 페이지 제한이 아니다. 대표 이미지와 주요 화면 3~5개는 아직 제작·촬영하지 않았다.

## 2쪽 서비스 소개

**서비스 유형:** 웹 서비스. 모바일 웹/PWA로 접근하며 앱 설치 없이 사용하도록 개발한다. 제출 유형은 완성된 웹 URL을 기준으로 기재한다.

**서비스 개요:** 장병과 가족이 공개 만남 거점, 남은 시간과 동행자의 여행 조건을 바탕으로 강원 접경지역 관광 미션을 함께 계획하고 기록하는 모바일 관광 여권 서비스.

**주제 선정 이유:** 강원 접경지역을 방문하는 장병과 가족은 유명 관광지를 찾는 것뿐 아니라 제한시간, 부모의 보행 부담, 예약·신분확인 조건을 함께 살펴야 한다. 군번여지도 강원은 관광정보를 공개 거점까지 돌아올 시간 여유와 가족의 여행 조건에 연결한다. 실제 부대명과 군번, 정확한 복무지 정보 대신 공개 관광장소와 최소한의 여행 기록을 사용한다.

## 3쪽 서비스 핵심 기능

1. **오늘의 복귀 미션:** 역할·권역·시간·이동수단 입력에서 미션과 공개 거점까지의 추정 마진, 관광 상세정보 확인으로 연결한다.
2. **부모 브리핑:** 부모가 방문 조건을 독립적으로 입력하고 도보 추정, 식사·실내 후보, 무장애 편의시설 정보를 확인한다.
3. **비무장 패스포트와 가족 권한:** 계획·본인 기록 스탬프를 저장하고 같은 브라우저에서 초대·공유범위·권한 회수를 체험한다.
4. **개인정보 없는 공유 카드:** 허용한 관광기록 항목으로 카드와 공유 문구를 만든다.
5. **데이터 활용 근거와 오류 대응:** 현재 API 수신, 원천 데이터, 계산 가정, 상세정보의 빈값·실패를 구분하여 표시한다.

휴가회수 레이더는 체크리스트와 현충시설 등재 목록을 제공하는 보조 화면이다. 이번 5개 핵심 흐름에서는 이를 별도 핵심 기능으로 확대하지 않는다. 보상 인정이나 공적 방문 인증은 제공하지 않는다.

## 5쪽 지역 특화 서비스 구현

**특화 지역명:** 강원특별자치도. 주 대상은 철원·화천·양구·인제·고성 접경 5군이며 춘천·속초는 방문 관문 권역으로 설정한다.

**구현 내용:** 접경 5군의 통일부 DMZ 관광·카페와 국가보훈부 현충시설 원천자료를 공통 장소 모델로 구성했다. 관광정보와 가족 여행 조건을 연결해 강원에서 짧게 머무르고 돌아올 미션을 계획하도록 한다. 비무장 패스포트는 접경 5군의 독립 챕터를 제공한다. 춘천·속초는 화면에서 선택할 수 있지만 현재 기본 파일은 접경 5군 중심이므로 해당 권역은 실제 관광 API 수신이 필요할 수 있다.

강원 안의 여러 기초지자체를 연계하는 구성이다. 전국 추천이나 다른 광역 지역으로 제출 범위를 확장하지 않는다. 기존 제안의 전국 확장은 향후 발전방향으로만 다룬다.

## 6쪽 핵심 기능 1 오늘의 복귀 미션

**기능 설명:** 장병의 여행 조건에 맞는 2~3개 장소 미션 초안을 구성하고 공개 거점까지 돌아올 추정 안전마진과 방문 확인사항을 함께 보여준다.

| 흐름도 단계 | 현재 화면·조작 | 처리와 표시 |
|---|---|---|
| 1. 역할 선택 | 오늘의 여행 → 현역 장병 → 오늘의 복귀 미션 만들기 | 역할에 맞는 시작 화면으로 이동 |
| 2. 조건 입력 | 상황·권역·동행자·이동수단·남은 시간·공개 거점·도보 상한·추가 버퍼 선택 | 현재 화면의 조건을 미션 생성과 마진 계산에 사용 |
| 3. 미션 비교 | 가족·회복·평화·실내 후보 중 제공되는 미션 선택 | 장소 타임라인, 도보 추정, 마진과 확인사항 표시 |
| 4. 근거 확인 | 계산 근거와 방문 조건 열기, TourAPI 장소의 상세·무장애 정보 조회 | 차감 시간 구성, 예약·신분확인, 관광 상세·이용정보·무장애 필드 확인 |
| 5. 계획 저장 | 패스포트에 계획 담기 | 방문을 확정하지 않고 계획만 여권에 추가 |

계산은 직선거리×우회계수와 수단별 가정 속도, 체류·대기·혼잡·날씨·동행 버퍼를 사용한다. 실제 도로·막차·교통량이나 부대 복귀 경로를 검증하는 기능은 아니다. 안전권은 시간상 추정 분류이며 방문조건 확인과 구분한다. Kakao 지도가 연결되지 않으면 실제 도로가 아닌 위치 개략도를 표시한다. 1박 2일은 숙박·휴식 시간을 확보하는 초안이며 예약·다음 날 운영 검증은 없다.

**화면 캡처:** 미촬영. **검증 상태:** 구현 코드 확인, 최종 브라우저·실API 연계 시연 대기.

## 7쪽 핵심 기능 2 부모 브리핑

**기능 설명:** 부모가 자녀의 초대 여부와 관계없이 본인의 방문 조건을 입력하여 가족 여행을 준비한다. 초대 연결 후에는 허용된 범위의 미션을 보고 제안할 수 있다.

| 흐름도 단계 | 현재 화면·조작 | 처리와 표시 |
|---|---|---|
| 1. 부모 조건 입력 | 부모 브리핑에서 권역·날짜·자차/대중교통·도보 시간·식사 선호 선택 | 장병 역할의 권역과 별도로 부모 방문 권역 지정 |
| 2. 브리핑 만들기 | 우리 가족 브리핑 만들기 | 가족 미션 초안, 도보 추정·주차 미확인·실내·식사 후보 표시 |
| 3. 편의시설 확인 | 계단과 주차부터 확인해요 → 장소 상세 열기 | 무장애 목록에서 관광·문화시설 후보의 주차·접근 동선·출입구 등 제공항목 표시 |
| 4. 가족 제안 | 미션 제안 권한으로 로컬 초대 연결 → 자녀에게 이 미션 제안 | 자녀 역할의 패스포트에 제안 표시; 권역이 다르면 변경 안내 |

부모 날짜는 현재 브리핑에 표시되며 선택한 날짜의 예약·운영 가능 여부를 확정하지 않는다. 식사 선호는 설명에 표시되지만 메뉴·알레르기 적합도를 검증하는 추천은 아니다. 실내 후보는 명칭·분류 기반이며 실제 실내·개방 여부를 확인해야 한다. 무장애 상세는 같은 권역의 비교 후보로 제공되고 모든 후보가 현재 미션의 정류장이라는 뜻은 아니다. 전체 동선의 무장애 적합성을 보장하지 않는다.

**화면 캡처:** 미촬영. **검증 상태:** 무장애 목록 108건 실측 보고서 있음. 현재 배포 화면에서 목록·상세까지 이어지는 실통합은 대기.

## 8쪽 핵심 기능 3 패스포트와 가족 권한

**기능 설명:** 강원 접경 5군의 여행 계획과 스탬프를 브라우저에 저장하고 사용자에게 공유범위 통제 경험을 제공한다.

| 흐름도 단계 | 현재 화면·조작 | 처리와 표시 |
|---|---|---|
| 1. 계획 확인 | 패스포트에서 저장한 미션 열기 | 권역별 챕터에 계획 표시 |
| 2. 본인 기록 | 입경·전환·복귀 스탬프 선택 | 여행 후 사용자가 직접 기록하는 스탬프. 공적 인증과 구분 |
| 3. 초대 생성 | 가족 초대코드 만들기 | 같은 브라우저에서 24시간 유효한 체험 코드 생성 |
| 4. 공유범위 선택 | 여권·미션범위·식사·제안·동행 권한 토글 | 허용한 정보만 가족 화면에 투영 |
| 5. 연결·회수 | 부모 역할로 연결 체험 → 허용된 정보로 연결하기 → 공유범위 해제/공유 해제 | 권한 변경을 조회 범위에 반영하고 연결 회수. 코드 재생성 시 이전 연결 해제 |

현재 연결은 서버 회원인증이나 다른 기기 가족 동기화가 아닌 **동일 브라우저 로컬 체험**이다. 계획·스탬프·초대 상태는 브라우저 저장소를 사용한다. 부모 입력과 제안 등 모든 상태가 영구 저장되는 것은 아니다. 동행 스탬프 추가는 해당 공유권한을 확인하지만 실제 동행을 인증하지 않는다. 부대명·군번·휴가증·신분증 업로드 입력을 제공하지 않는다.

**화면 캡처:** 미촬영. **검증 상태:** 권한 투영·만료·회수 처리 코드 및 관련 테스트 정의 확인; 본 초안 작성에서는 테스트를 실행하지 않았다.

## 9쪽 핵심 기능 4 개인정보 없는 공유 카드

**기능 설명:** 여권의 관광기록에서 공개할 항목만 골라 카드 미리보기, SVG 이미지와 공유 문구를 생성한다.

| 흐름도 단계 | 현재 화면·조작 | 처리와 표시 |
|---|---|---|
| 1. 기록 선택 | 여권의 개인정보 없는 공유 카드 만들기 | 해당 미션의 공유 미리보기 표시 |
| 2. 허용 항목 구성 | 자동 구성 | 강원 권역·미션명·허용된 스탬프·서비스 문구만 사용 |
| 3. 저장 또는 복사 | 공유 이미지 저장 / 공유 문구 복사 | SVG 다운로드 또는 클립보드 복사 |

정확한 시간·좌표·실명·군번·복귀시각·상세 경로 필드를 공유 결과에 포함하지 않는다. 현재 앱에는 사용자 실명이나 부대정보를 입력하는 흐름 자체가 없다. 카드 생성은 공개 게시가 아니며 SNS 자동 전송 기능도 제공하지 않는다. SVG 렌더링·글자 배치·모바일 저장은 제출 전 실제 파일과 브라우저에서 확인한다. 계획만 담은 미션을 완료한 여행으로 표시하지 않는다.

**화면 캡처·실제 저장물 확인:** 대기.

## 10쪽 핵심 기능 5 데이터 근거와 오류 대응

**기능 설명:** 한국관광공사 API를 장소 후보·상세·부모 편의시설 정보에 연결하고, 현재 수신상태와 원천자료·미확인 항목을 사용자가 구분하도록 한다.

| 흐름도 단계 | 현재 화면·조작 | 처리와 표시 |
|---|---|---|
| 1. 관광정보 조회 | 권역 변경 또는 실제 API 다시 호출 | 서버가 법정동 코드를 조회하고 관광지·문화시설·축제·숙박·음식점 후보 요청 |
| 2. 현재 수신 확인 | 데이터·출처 | 현재 권역 수신 건수·시각·유형별 수신상태 표시 |
| 3. 원천 검사 | 장소·권역 검색 → 원천·품질 플래그 | source/id, 좌표, 품질 플래그, 검증일 확인 |
| 4. 오류·빈값 대응 | API 미연결 또는 상세 일부 실패 | 미연결 안내와 공개 원천 후보 제공. 상세 빈값을 시설 부재로 단정하지 않음 |

관광 API 원문은 운영 DB와 서비스워커 캐시에 영구 저장하지 않고 화면 요청마다 서버를 통해 조회하는 코드다. 화면 후보는 유형별 첫 100개이므로 지역 전체 관광자원 전수조사 수치로 쓰지 않는다. 기본 공개자료는 통일부 DMZ 관광·카페와 보훈부 현충시설을 정규화한 원천 노드다. 파일만으로 공사 API 필수 요건을 충족했다고 표시하지 않는다.

**화면 캡처:** 현행 국문 API 재검증 후 촬영. **검증 상태:** 현재 `blocked_missing_key`; API 오류 대체와 정상 연계 모두 배포환경 브라우저 검증 필요.

| API | 구현된 연결 지점 | 데이터 활용 | 현재 검증 상태 |

집중률·중심 관광지·연관 관광지는 매뉴얼과 연결 제약을 조사했지만 현재 핵심 화면에 실제 적용한 API로 제출하지 않는다. 최종 제출 체크박스·인증키·기능설명서는 **실제로 서비스에서 활용한 API만** 일치시킨다. API 키와 키가 포함된 URL은 이 문서·이미지·클라이언트에 포함하지 않는다.

## 13쪽 차별성과 발전계획

**차별성:** 제한시간과 공개 거점까지의 시간 여유를 관광정보에 결합하고 부모를 독립적인 여행계획 사용자로 설계한다. 관광 추천에서 끝나지 않고 계획·여권·공유 권한으로 경험을 연결한다. 미확인 운영·접근조건을 숨기지 않으며 군번과 실제 부대정보를 요구하지 않는다. 출처를 통한 판단 근거를 확인할 수 있다.

**발전계획:** 우선 현행 관광 API와 모바일 시연을 안정화하고, 시연 장소의 예약·출입·보행 조건을 반복 검증한다. 이후 실제 가족 계정과 기기 간 연결, 검증된 길찾기·교통과 예측정보의 보정, 가족 이용성 검증을 순차적으로 추진한다. 접경 5군의 관광·식사·휴식 연결 성과를 측정하고 지역기관 협력 가능성을 검토한다. 협약·공식 연계·관광소비 효과가 이미 확정된 것처럼 표현하지 않는다.
