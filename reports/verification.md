## 검증 범위와 남은 확인

실제 브라우저 클릭·실기기 화면·PWA 설치는 이번 작업에서 실행하지 않았다. HTTP 렌더·서버 API·정적 검사·단위 테스트와 구분한다. 디자인 조사에는 경쟁사 공식 제품과 개발사 스크린샷을 사용했으며, 자체 앱의 사용자 테스트를 수행했다는 뜻은 아니다.

전체 `npm run lint`는 통과하지 않는다. 기존 shadcn 공통 컴포넌트의 접근성 태그 규칙, React compiler의 effect 상태 설정 규칙, unknown 문자열 변환 등 프로젝트 전반의 규칙 오류가 남아 있다. 이번 개편에서 생긴 미사용 항목·지도 ref의 render 중 쓰기·재할당 없는 let은 제거했다. 타입 검사·테스트·빌드 성공을 lint 통과로 표현하지 않는다.

교통·보행 시간은 추정이고 현장 접근·예약·막차·알레르기 적합성·보상 인정은 보장하지 않는다. 예보는 시군청 대표 격자의 향후8시간이며 가족의 미래 방문일 예보가 아니다. 방문 조건과 추정 복귀 여유를 별도로 안내한다. 가족 초대는 같은 브라우저 체험이며 다른 기기와 연결되지 않는다.
